# مافيا أونلاين

لعبة مافيا متعددة اللاعبين: غرف بكود، 6 إلى 10 لاعبين، والأماكن الفاضية بتتعبّى بلاعبين آليين.

## التشغيل على جهازك
1. ثبّت Node.js (الإصدار 18 أو أعلى).
2. افتح الطرفية داخل هذا المجلد:
   npm install
   npm start
3. افتح http://localhost:3000 بعدة نوافذ لتجرب اللعب.

## النشر على الإنترنت (Render، مجاني)
1. ارفع المجلد على GitHub.
2. على render.com اختر New > Web Service واربطه بالمستودع.
3. Build Command: npm install
   Start Command: npm start
4. بعد النشر بيعطيك رابط عام، وأي حدا يفتحه يقدر يلعب.
ملاحظة: الخطة المجانية بتنام بعد فترة خمول، وأول دخول بعدها ممكن يتأخر نصف دقيقة.

## الحسابات والمتجر
- تسجيل بالاسم وكلمة السر (كلمات السر مشفّرة بـscrypt)، أو اللعب كضيف بدون حفظ.
- كل لعبة بتعطي عملات وخبرة (10 للمشاركة، و25 زيادة للفوز). المستوى كل 100 خبرة.
- المتجر: إطارات وألوان أسماء شكلية فقط، بدون أي أفضلية باللعب.
- البيانات بتنحفظ بملف data.json. على Render المجاني الملف بيروح مع كل إعادة نشر، فللإنتاج انقل البيانات لقاعدة بيانات (Supabase أو Postgres) أو استخدم قرص دائم وحدد مساره بالمتغير DATA_DIR.

## الأمان والإشراف
- فلتر شتائم بسيط (قائمة قصيرة بأول server.js، وسّعها حسب احتياجك)
- حد لسرعة الرسائل، وبلاغات: 3 بلاغات من لاعبين مختلفين بتكتم اللاعب بالغرفة
- شات سري للمافيا، وإعادة اتصال اللاعب لنفس اللعبة بعد انقطاع

## الهيكل
- server.js: السيرفر ومنطق اللعبة (الغرف، الليل والنهار، التصويت، الأدوار)
- index.html: واجهة اللاعب
- الصور (mafia.jpg وغيرها): صور الأدوار، كلها بنفس المجلد بدون مجلدات فرعية

## الخطوات الجاية
- نقل البيانات لقاعدة بيانات دائمة
- Battle Pass موسمي ودفع حقيقي للعملات (بوابة دفع)
- شات صوتي (WebRTC، يحتاج خادم TURN)
- لوحة إدارة لحظر الحسابات نهائياً
